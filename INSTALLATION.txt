DÉPENSES ET EXPORT EXCEL — TOURNÉE MARION

1. Ouvrir le projet Supabase utilisé par le calendrier :
   https://supabase.com/dashboard/project/iybjtvwdnqnebuexesiz/sql/new
2. Copier le contenu de sql/installer_depenses.sql dans le SQL Editor.
3. Cliquer sur Run. Le résultat doit afficher la table avec RLS activé
   et quatre règles d’accès. Le script peut être relancé.
4. Publier les modifications GitHub avec les trois fichiers ensemble :
   calendrier.html, finance-core.js et calendrier-finances.js.
5. Recharger le calendrier.

UTILISATION

Choisir le mois avec les flèches. Cliquer sur « Ajouter une dépense »
ou cliquer sur un jour, puis « Ajouter une dépense à cette date ».
Saisir la catégorie, le libellé et le montant positif à déduire.
La date reste dans le mois choisi. Une dépense peut être modifiée
ou supprimée depuis la liste du mois.

« Exporter Excel [année] » télécharge un fichier .xlsx pour l’année
affichée : janvier à décembre, puis Total annuel. Les 13 onglets
sont toujours présents, même pour les mois sans données.
Les chiffres d’affaires incluent toutes les tournées et les journées
payées ou non, selon la date de travail saisie dans le calendrier.
Les dépenses sont rattachées au mois de leur date.
Le résultat demandé est le CA moins toutes les dépenses et tous les
prélèvements, y compris le prélèvement salaire.
Le fichier comporte les détails et des formules recalculables dans Excel.
Les modifications faites dans Excel ne modifient pas le calendrier.

ACCÈS

Comme demandé, les dépenses sont partagées sans connexion ni code.
Les visiteurs du site peuvent les lire et les modifier.
La table des dépenses est distincte des journées et des patients.

ESTIMATION URSSAF ET CARPIMKO DANS EXCEL UNIQUEMENT

Pour une installation existante, exécuter
sql/ajouter_categories_cotisations.sql avant de publier la mise à jour.
Ce script autorise URSSAF et CARPIMKO sans modifier les anciennes dépenses.
Publier le fichier cotisations.js avec les autres fichiers du calendrier.

L'export Excel calcule les estimations via le moteur officiel URSSAF
Mon-entreprise (modèle TI intégrant la réforme de l'assiette sociale).
Aucun résultat d'estimation ni formulaire supplémentaire ne s'affiche
dans le calendrier. Aucun impôt sur le revenu n'est calculé.

Dans Total annuel : recettes et frais retenus à l'export, assiette sociale,
estimations URSSAF/CARPIMKO, paiements saisis et reste à provisionner.
Les cases jaunes permettent de retirer des versements la part qui règle
d'autres années. Un excédent chez un organisme ne compense pas l'autre.
Reclasser les anciennes dépenses « Cotisations » en URSSAF ou CARPIMKO.

Chaque mois comporte une provision indicative égale au total annuel
estimé divisé par douze. Elle ne s'ajoute pas aux dépenses réelles et
ne se déduit donc pas une seconde fois du résultat mensuel.

L'estimation part de toutes les journées et frais de l'année saisie.
Elle ne projette pas automatiquement les mois manquants. Compléter les
données de l'année pour une prévision annuelle complète. Les recettes
doivent correspondre aux encaissements attendus pour cette année.
Les prélèvements personnels et toutes les cotisations sociales sont
exclus des frais de calcul. Vérifier l'usage professionnel et les
amortissements dans les frais retenus.

Les estimations sont figées au moment de l'export : si recettes ou frais
sont modifiés dans Excel, les provisions affichent « Réexporter ».
Les paiements et corrections des cases jaunes restent recalculables.
Le classeur conserve toujours ses 13 onglets, même si le moteur URSSAF
est indisponible : le bloc indique alors que l'estimation est indisponible.

Périmètre vérifié : année 2026, PAMC remplaçante exclusivement, frais réels,
entreprise individuelle à l'IR, activité sur l'année entière en métropole,
entièrement conventionnée sans dépassement. Pas d'ACRE, exonération,
indemnités maladie/maternité, revenus étrangers ou conjoint collaborateur.
CARPIMKO estimée à revenu constant, hors régularisations antérieures.
Seuls les montants agrégés et hypothèses sont transmis au moteur URSSAF,
sans patients, noms ni libellés. Aucune connexion ou code n'est ajouté.

Sources :
https://mon-entreprise.urssaf.fr/api/v1/modeles/ti/evaluate
https://www.carpimko.com/je-suis-en-activite/cotisations/selon-mes-revenus
INSTALLER SUR UN TÉLÉPHONE OU UN ORDINATEUR

Le bouton « Installer l’appli » est disponible sur les tournées et le calendrier.
Chrome / Edge : le bouton ouvre la proposition d’installation si elle est disponible.
iPhone / iPad : le bouton explique comment ouvrir le site dans Safari puis utiliser
Partager > Sur l’écran d’accueil > Ajouter (activer « Ouvrir comme app » si proposé).
L’icône « Marion » ouvre les tournées ; le calendrier reste accessible depuis celles-ci.
Une connexion Internet reste nécessaire. Aucun changement de base de données requis.
Les fichiers manifest.webmanifest, install-app.js, install-app.css et le dossier icons
doivent être publiés avec les pages HTML. Pas de cache hors ligne ni de service worker.
