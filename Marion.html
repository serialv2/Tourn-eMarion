Organisation de tournée infirmière

Patients, ordre de tournée, itinéraires Google Maps fractionnés, Waze, sauvegarde automatique et export/import.

1. Liste des patients

Format conseillé : Nom;Adresse;Horaire;Note — une ligne par patient.
La sauvegarde complète contient les patients + l’ordre de tournée sélectionné.
Restauration sur iPhone : appuie sur un bouton ci-dessous, puis choisis ton fichier JSON dans Fichiers / iCloud Drive / Sur mon iPhone.
Secours si iPhone refuse le fichier : copie/colle le JSON dans la zone ci-dessous.
Sauvegarde automatique dans ce navigateur. Pour ne rien perdre si tu changes de téléphone/PC, utilise “Télécharger sauvegarde complète”.

2. Ordre de tournée

Pour plus de 9 étapes, clique sur “Fractionner Google Maps”. La page crée plusieurs itinéraires : segment 1, segment 2, segment 3…
